## What I'm building

- **[purpl-brain](https://github.com/skalrn/purpl_brain):** open-source decision memory for codebases edited by multiple independent AI coding agents. A pre-action guardrail (`analyze_impact`) over an MCP server lets an agent see which prior decisions a change would break before it writes code. Neo4j decision graph plus Qdrant semantic search, so contradictions that share no wording are still caught. [Write-up](https://medium.com/@skalrd/what-i-learned-building-a-decision-log-that-tells-ai-agents-what-theyre-about-to-break-04d3b0a5426b).
- **career-ops interview modes:** three interview-prep modes (plan, practice, debrief) plus the session-transcript producer, contributed to [santifer's career-ops](https://github.com/santifer/career-ops). Built to the project's never-fabricate rule; other contributors' features now build on the transcript format. [PR #956](https://github.com/santifer/career-ops/pull/956).
- **[Repo-context-aware AI code review](https://github.com/skalrn/repo-context-aware-rag-ai-code-review):** RAG over repository context (n8n, Qdrant, LLMs) that generates project-specific feedback on GitHub pull requests.
