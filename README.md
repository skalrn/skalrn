## What I build

- **[purpl-brain](https://github.com/skalrn/purpl_brain):** decision memory and a pre-action guardrail for codebases edited by multiple independent AI coding agents. An agent calls `analyze_impact` over MCP to see which prior decisions a change would break before it writes code. Neo4j decision graph plus Qdrant semantic search, so contradictions that share no wording are still caught. [Write-up](https://medium.com/@skalrd/what-i-learned-building-a-decision-log-that-tells-ai-agents-what-theyre-about-to-break-04d3b0a5426b).
- **[career-ops interview modes](https://github.com/santifer/career-ops/pull/956):** plan, practice, and debrief modes plus the session-transcript producer, merged into santifer's career-ops. Built to its never-fabricate rule; other contributors' features now build on the transcript format.
- **[Repo-context-aware AI code review](https://github.com/skalrn/repo-context-aware-rag-ai-code-review):** RAG over repository context (n8n, Qdrant, LLMs) that generates project-specific feedback on GitHub pull requests.
